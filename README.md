# DAJOMS GROUP — Etiquetas y Soluciones de Identidad Textil

Sitio web comercial y presentaciones para DAJOMS GROUP, especialista en etiquetas tejidas, impresas y soluciones de identidad textil para marcas, fabricantes y empresas.

## 📁 Estructura del Proyecto

```
dajoms/
├── index.html                          # Sitio web principal (responsive)
├── presentacion-impresa.html           # Presentación comercial (12 slides)
├── tarjetas-presentacion.html          # Tarjetas de presentación (doble cara)
├── carta-presentacion.html             # Carta comercial
├── assets/                             # Recursos (logos, imágenes, fotos)
│   ├── DAJOMSlogo.png
│   ├── boton_women.png

│       └── ...
├── styles/                             # CSS (si se modulariza)
├── js/                                 # JavaScript (si se modulariza)
└── README.md                           # Este archivo

```

## 🚀 Características

### DAJOMS Website (`index.html`)
- **Responsive**: Totalmente adaptado para desktop, tablet y móvil
- **Dinámico**: Navegación suave con React
- **Multi-marca**: Selector W/M/U para visualizar productos por categoría (Women, Men, Unisex)
- **Secciones**:
  - Hero con propuesta de valor
  - Líneas de producto
  - Galería de clientes
  - Nosotros / Historia
  - Contacto y cotización
  - Footer con información

### DAJOMS Presentación Impresa (`presentacion-impresa.html`)
- **12 diapositivas** listas para imprimir o PDF
- **Navegación**: Botones + flechas del teclado
- **Contacto**: Dos versiones (Daniela Reyes Cázares y Miguel Martínez Vázquez)
- **Optimizada**: Para A4 horizontal, márgenes amplios, tipografía legible

### DAJOMS Tarjetas (`tarjetas-presentacion.html`)
- **Doble cara**: Frente + Reverso
- **Dos versiones**: Managers (blanco/rosa) + Ventas (gris oscuro)
- **Medidas reales**: 85 × 55 mm
- **Impresión**: Botón para PDF a 300 dpi

### DAJOMS Carta (`carta-presentacion.html`)
- Documento comercial formal
- Datos de contacto
- Firma

## 🔤 Tipografía

- **Montserrat**: Títulos y elementos de navegación (300-800)
- **Inter**: Cuerpo de texto y UI (300-600)
- **Cormorant Garamond**: Taglines y elementos estilísticos
